# v0.11.0 - 本地化维护版

本版本基于上游 `craft-agents-oss` v0.11.0，主要聚焦基础稳定性、打包资源补齐和一批上游问题修复。

## 主要修复

- 修复 macOS 中文输入法场景下，输入框自动大写干扰中文输入的问题。
- 修复 Opus 4.8 / 4.7 模型描述重复的问题。
- 修复编辑连接时遮罩 API Key 被误作为真实凭证回传的问题。
- 修复生产环境 auto-update 诊断日志不可见的问题。
- 修复 Agent 输出 `file://` 本地链接时无法在应用内正确打开的问题。
- 修复 Skill 目录为符号链接时无法识别的问题。
- 修复 Write 工具覆写已有文件时 diff 只显示全量新增的问题。

## 打包与运行时

- 修复打包后缺少 SDK 或子进程资源导致应用启动失败的问题。
- macOS 打包改走 `build-dmg.sh`，确保 SDK 与子进程资源被正确复制。
- 修复 macOS Dock 图标在深色模式下被固定图标覆盖的问题。
- Electron 打包保留经典 `icon.icns`，避免新图标在不同系统环境下渲染不一致。
