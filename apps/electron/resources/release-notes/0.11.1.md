# v0.11.1 - 审阅栏、会话资源与内嵌终端

本版重点优化界面工作流、右侧审阅栏、会话资源面板、对话定位器、内嵌终端与历史对话体验。

## 新增

- **右侧审阅栏**：在会话右侧提供信息、文件、终端、浏览器等辅助视图。
- **会话资源悬浮面板**：顶部按钮统一收纳标题、上下文、会话文件、输出和来源。
- **对话内容定位器**：聊天区左侧新增轻量刻度定位，滚动时同步当前片段，悬停显示标题和摘要。
- **内嵌终端**：可在审阅栏内直接打开当前工作区终端，支持输入、尺寸调整和进程退出回传。
- **会话列表轻量摘要卡**：悬停时展示标题、摘要、空间、工作目录和 Git 分支。

## 改版与优化

- 主聊天区会在资源面板打开时自动让出宽度，避免悬浮面板压住消息、滚动条或输入区。
- 来源入口接入底部输入框已有来源选择器；输出入口可快速生成当前会话的可交付文件或站点。
- 右侧审阅栏默认展示会话信息，并保留文件、终端、浏览器快捷切换。
- 对话定位器样式重新调整，默认刻度更细、更短、更轻，选中态更克制并带平滑过渡。
- 消息列表悬停预览改为简洁摘要，不再加载完整消息和文件清单。
- 设置页中文文案调整，Messaging 设置页内容区补齐左右留白。

## 修复

- 修复右侧栏或悬浮面板覆盖主对话内容的问题。
- 修复打开资源面板后聊天主区域不自适应的问题。
- 修复资源面板点击外部即关闭、无法持续操作的问题。
- 修复来源和输出入口没有接入实际交互的问题。
- 修复历史会话打开时容易停在顶部的问题，并新增滚动位置设置。

## 构建与打包

- Electron 打包补齐终端页面、terminal preload、子进程和运行时资源。
- macOS 继续使用经典 `icon.icns`，避免图标在不同环境下渲染不一致。
