# v0.11.10 - 探索工作台、附件上下文与设置收口

本版本统一了「会话 / 网页」探索入口，重做探索首页和网页恢复体验，并补齐文件夹上下文、标签管理与设置导航。

## 探索与网页工作区

- 探索统一为「会话 / 网页」双模式入口，中间列表随模式切换；探索首页不再错误高亮历史会话或网页标签。
- 主导航创建按钮跟随当前模式显示「新建会话」或「新建网页」，移除重复的「所有会话」一级入口。
- 探索首页调整为统一输入、近期工作概览和 3–5 条继续执行建议；分析频率、开关与建议数量可在设置中管理。
- 浏览器空白页使用固定地址/搜索输入框：网址直接访问，普通文本使用 Google 搜索；空白项与加载后的标题、地址显示更准确。
- 应用退出前保存实时网页标签、活动标签、图标、访问时间和页面状态，并刷新 Chromium 存储；重启后继续保留网页会话与登录态。

## 会话附件与快捷操作

- 会话输入支持选择或从 Finder 拖入文件夹作为上下文，并与普通文件共用附件预览、去重、删除和草稿恢复流程。
- 附件预览按文件夹、图片、视频、音频、PDF、文档和其他类型显示对应图标与元信息；文件夹以引用语法传入会话。
- 会话右上角新增快捷键入口，复用右侧审阅面板展示原有快捷键页面，重复打开时会聚焦已有面板。

## 设置与标签管理

- 设置导航改为单层分组列表，移除重复的父子选中状态，同时保留全部原设置页面和独立窗口能力。
- 标签从主导航移入设置，支持新增、删除、层级管理，以及查看和维护标签中的会话；会话筛选入口继续保留。
- 探索设置加入工作概览开关、刷新周期和建议数量，信息页、插件页与数据表同步收敛到现有设计 token。

## macOS 与工程整理

- macOS DMG 使用 Retina 双分辨率安装背景，窗口、应用图标、Applications 链接与拖拽提示按参考安装器尺寸对齐。
- 版本统一升级到 `0.11.10`，同步全部 workspace 清单、锁文件和 README 版本标记，修复上个版本遗留的元数据不一致。

## 验证

- Renderer 正式构建、i18n parity/sort/coverage、版本一致性和差异检查通过。
- 浏览器输入、探索分析、文件夹附件、退出持久化与自动更新策略专项测试通过。
