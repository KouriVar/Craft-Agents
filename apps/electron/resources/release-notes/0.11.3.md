# v0.11.3 - 交互式可视化与 Cowart Widget

## 主要更新

- 新增对话内交互式可视化运行环境，支持图表、模拟器、数据探索器与动态控件直接在回答中运行。
- 内置完整 Visualize 技能与 Codex 原版交互资源，安装后无需额外配置。
- 新增 Cowart Widget 宿主链路，可由 Agent 自动在右侧审阅栏打开当前项目画布。
- 支持可视化组件自适应高度、Lucide 图标、Tooltip 与确认后的对话回传。
- 增强 Widget 沙箱、CSP、文件路径限制、符号链接逃逸防护与 Cowart 本地服务校验。
- 新增打包资源验证，发布前逐文件核对内置资源和 Electron 必需产物。

## 修复与优化

- 可视化外层画布自动匹配 Craft Agent 的明暗主题，不再强制显示白色背景。
- 移除 Visualize 生成内容外围默认的根级内边距，使其与消息内容区自然衔接。
- 保留图表、卡片、按钮和控件自身的原始样式与内部间距。
