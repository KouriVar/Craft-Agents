# v0.11.4 - 五层扩展协议与插件市场

本次版本补齐了 Craft Agent 的五层开放扩展协议，覆盖可移植技能、插件包、MCP 工具、交互式 Widget 与宿主/会话权限。同时将 Pi 升级至 0.80.7，并新增默认接入 OpenAI 公开目录的插件市场。

## 扩展协议

- **五层扩展架构**：补齐技能、插件、MCP、Widget 和宿主权限五层能力，并加入对应的生命周期、诊断、恢复与安全边界。
- **可移植技能元数据**：兼容 `globs`、`alwaysAllow`、`requiredSources` 等标量或混合列表字段，导入不同生态的 `SKILL.md` 更加稳定。
- **项目技能发现**：从当前工作目录向上发现 `.agents/skills`，直至 Git 仓库根目录；距离更近的同名技能优先。
- **OpenAI 技能元数据**：支持读取 `agents/openai.yaml`，用于显示信息、默认提示词、隐式调用策略、工具依赖和数据源依赖。

## 插件与市场

- **插件包兼容**：支持 `.craft-plugin`、`.codex-plugin` 和 `.claude-plugin` 清单，统一发现技能目录、MCP/App 配置和 Widget 资源。
- **插件工作区**：左侧栏新增「插件」，复用 Craft Agent 原有的列表与详情布局。
- **安装与管理**：支持从 Git 安装、本地添加、启用、停用、卸载及安全删除托管插件。
- **插件权限**：支持插件默认工具策略与单工具权限覆盖，并遵循 Explore、Ask、Execute 会话权限。
- **MCP 诊断**：显示插件 MCP 的依赖缺失、身份验证、Schema、传输错误和已发现工具。
- **插件市场**：默认接入公开的 `openai/plugins`，支持搜索、刷新、查看详情和直接安装选中的插件。
- **自定义市场**：支持添加或移除其他 Git marketplace，并兼容 `owner/repo` 简写、分支、标签和稀疏路径。
- **轻量缓存**：市场使用稀疏检出，仅拉取市场清单和选中的插件目录，避免下载整个仓库。
- **兼容提示**：依赖 OpenAI Connector 或外部账号的插件会显示说明；暂不支持的 NPM marketplace 包会明确标记。
- **安装安全**：校验 marketplace 子目录、真实路径和符号链接，阻止路径穿越与仓库外文件访问。

## MCP Apps 与 Widget

- **通用 MCP Apps 宿主**：插件可在消息内或右侧审阅栏渲染标准 MCP Apps 界面，不再需要为 Canvasight 等应用逐个制作专用适配。
- **结构化结果**：完整保留 MCP `structuredContent`、`_meta`、资源描述和工具 annotations。
- **交互桥接**：支持主题同步、结构化结果注入、工具调用、后续消息回传与最小 `window.openai` 兼容接口。
- **权限保护**：Widget 工具调用经过会话模式、用户确认和插件策略检查，并由 CSP 限制可访问的脚本、资源与网络地址。
- **会话恢复**：打开的 MCP App 标签通过新的会话绑定连接安全恢复；会话删除或应用退出时会关闭插件 MCP 客户端和连接池。

## Pi 与工具运行时

- **Pi 0.80.7**：升级 Pi 运行时，加入会话级和连接池级动态工具目录。
- **动态工具更新**：已有工具可原地启用或停用；新增工具或 Schema 变化时采用安全的会话重建流程。
- **MCP 只读提示**：保留 `annotations.readOnlyHint`，允许声明为只读的插件工具在 Explore 模式下按规则运行。

## 可视化与 Cowart

- **内置 Visualize 技能**：安装后即可生成交互式图表、模拟器、数据探索器和控件。
- **内联可视化**：交互内容可直接显示在助手回答中，支持自适应高度、主题切换和确认式后续操作。
- **Cowart 集成**：Cowart 工具可直接在右侧审阅栏打开当前项目画布，并将确认后的操作回传给当前会话。

## 修复与构建

- 修复流式和已完成消息走不同渲染路径时，Widget 只能在部分消息中显示的问题。
- 修复完整 HTML 文档重复嵌套、内容高度被截断和主题切换后未同步的问题。
- 移除可视化内容外围多余的根级内边距，并让外层画布跟随 Craft Agent 当前主题。
- macOS 构建统一使用 `icon.icns`，避免 Dock 图标在启动后改变外观。
- 打包流程会校验资源文件、Electron 主进程、preload、renderer、插件和 Widget 运行资源。

## 破坏性变更

- 无。
