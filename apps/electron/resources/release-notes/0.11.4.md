# v0.11.4 - Open Extension Runtime and Plugin Marketplaces

This release completes Craft Agent's five-layer open extension runtime across portable skills, plugin packages, MCP tools, interactive widgets, and host/session permissions. It also upgrades Pi to 0.80.7 and adds a searchable plugin marketplace with OpenAI's public catalog built in.

## Improvements

- **Pi 0.80.7 dynamic tools**: Upgraded the Pi runtime and added scoped session/pool tool catalogs. Previously registered tools can now be enabled or disabled in place, while new or changed schemas use a safe session-rebuild fallback.
- **Agent extension runtime roadmap**: Added a bundled architecture note defining Craft Agent's five-layer extension target and its local-first compatibility boundaries.
- **Portable skill metadata**: Skill loading and validation now normalize scalar and mixed string-list metadata for `globs`, `alwaysAllow`, and `requiredSources`.
- **Project skill discovery**: Project-local `.agents/skills` directories are discovered from the working directory up to the Git repository root, with nearer skills overriding parent skills.
- **Portable OpenAI skill metadata**: Skills can read supplemental `agents/openai.yaml` metadata for display, prompt, invocation, tool, and source dependency hints.
- **Plugin packages**: Added readers for `.craft-plugin`, `.codex-plugin`, and `.claude-plugin` manifests, including skills, MCP/App configs, and widget assets.
- **Plugin lifecycle**: Added workspace registration, Git and local installation, enablement, removal, persisted tool policies, MCP diagnostics, and session-safe cleanup.
- **Plugin workspace**: Added a sidebar Plugins view with the existing Craft Agent list/detail layout.
- **Plugin marketplaces**: Added a searchable marketplace browser with `openai/plugins` built in, custom Git marketplace sources, sparse cached checkouts, compatibility guidance, and selected subdirectory installation.
- **Plugin MCP tools**: Plugin MCP servers now merge into the session MCP pool with Codex-style stdio/http fields and dependency diagnostics.
- **MCP structured results**: Preserved MCP `structuredContent`, `_meta`, and tool annotations through proxy and rendering layers.
- **MCP Apps widget host**: Standard MCP Apps resources can render inline or in the review sidebar with CSP enforcement, structured result hydration, permission prompts, tool calls, follow-up messages, and a minimal `window.openai` bridge.
- **Session-owned extension runtime**: Widget tools inherit Explore, Ask, and Execute permissions; open widget tabs recover through fresh session-bound reconnects and close with their sessions.
- **Built-in visualizations**: Craft Agent ships with the `visualize` skill and supports inline interactive charts, simulators, and data explorers.
- **Cowart integration**: Cowart tools can open the project canvas directly in a review-sidebar tab and return confirmed follow-up messages.
- **Package validation**: Desktop builds verify copied resources and required Electron artifacts before packaging.

## Bug Fixes

- Inline widgets now render consistently in streaming and completed responses, preserve complete HTML documents, and grow beyond the previous height limit.
- Widget canvases follow the current Craft Agent theme without forcing a white iframe background.
- Generated visualization content no longer receives unwanted root padding.
- Packaged macOS builds consistently use `icon.icns` for the Dock icon.

## Breaking Changes

- None.
