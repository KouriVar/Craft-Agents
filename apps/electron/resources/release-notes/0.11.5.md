# v0.11.5 - 浏览器工作区、模型运行时与桌面体验

本次版本完成了主浏览器工作区的持久化能力与交互重构，补齐浏览器扩展、密码仓库、会话用量和专注模式，并将 Pi 升级至 0.80.10 的官方 ModelRuntime。Windows 中文界面同时改用内置思源黑体，无需额外安装字体。

Electron、共享运行时、CLI、无界面服务、WebUI 与内部工作区包现已统一使用 `0.11.5`，应用设置页、运行时请求头、安装包和更新清单不会再出现版本号不一致。

## 本地优化修复版

- 会话「信息」面板改用信息按钮与当前输入框的真实边界计算最大高度；窗口缩小时同步收缩，内容较少时保持自然高度，超出后仅在面板内部滚动，并统一使用输入区 `16px` 底部安全间距。
- 网页中的新窗口链接默认在左侧标签列表创建并激活新标签；按住 macOS `Option` 或 Windows/Linux `Alt` 点击时才打开独立弹窗。
- 关闭 CA 自定义代理时，内置浏览器继承系统代理/PAC；代理切换后主动关闭旧连接池，新路由无需重启即可生效。
- 修复 Windows 新标签页搜索框原生键盘焦点缺失的问题，避免中文输入法候选框飘到窗口顶部、输入框无法选中或无法输入。

## 主浏览器工作区

- **持久化浏览器**：新增三栏浏览器工作区，保存标签顺序、当前页面、Cookie、登录态、缓存、localStorage、IndexedDB、历史、收藏、下载、权限和扩展偏好。
- **Agent 共用 Runtime**：用户打开的网页与 Agent 浏览器控制共用同一 Browser Profile，可直接在已登录页面上继续研究、填写表单、截图和提取数据。
- **标签内操作区**：后退、前进、刷新、复制链接、收藏、密码、网站权限和扩展操作收进当前标签，不再占用网页上方的独立地址栏。
- **简化新标签页**：新标签页只保留居中的地址输入框；网址直接访问，其余文字通过 Google 搜索。
- **稳定的原生层级**：修复网页覆盖菜单、账号弹层、最新动态、通知和弹窗，以及折叠侧栏后网页占据顶部的问题。

## 浏览器扩展与密码

- **统一安装入口**：提供谷歌商店、微软商店、解压插件和导入插件四种入口，支持商店链接、CRX、ZIP 和已解压目录。
- **商店内直接安装**：兼容的 Chrome Web Store 与 Microsoft Edge Add-ons 页面可直接“安装到 Craft Agents”。
- **扩展管理**：展示真实图标、版本、说明、权限和来源，并支持启停、固定、隐藏、排序、弹出页、选项页和卸载。
- **可折叠扩展操作**：标签“更多”菜单在卡片内展开；固定扩展在分组折叠后仍保持可见并可直接运行。
- **浏览器密码仓库**：正式签名的 macOS 构建优先使用 Data Protection Keychain / iCloud Keychain，其他环境使用 Electron 本机加密存储；支持账号选择、Touch ID 填充、更新和删除。

## 会话信息与用量

- 会话右上角入口统一为“信息”，集中显示上下文、会话文件、输出、来源与 API 用量。
- 展示当前模型、服务商、上下文占用、输入 / 输出 Token、缓存读取 / 写入 Token 和预估费用。
- 费用说明区分官方 API、DeepSeek 标准价、订阅 / OAuth 和自定义兼容端点，实际账单仍以服务商为准。
- 信息面板会随窗口和输入框自动调整高度：内容少时保持紧凑，内容多时向下延伸，仅在用完整段可用空间后滚动。

## 专注模式与桌面体验

- 左上角布局菜单与 macOS“视图”菜单新增专注模式；启用后隐藏侧栏、会话列表、顶部栏和 macOS 窗口按钮。
- 鼠标移动到窗口顶部可临时唤醒顶部区域；进入时使用现有右上角通知提示 `⌘ + .` 或 `Ctrl + .` 快捷键。
- 专注状态不再跨应用重启保存，退出并重新打开应用即可恢复普通布局。
- 补齐 macOS 原生文件、编辑、视图、窗口和帮助菜单的中文名称。
- Windows 默认内置 Source Han Sans CN 2.005R 可变字体，改善中文小字号清晰度；macOS 继续使用系统字体与苹方。

## Pi 0.80.10 与模型运行时

- Pi SDK 升级至 `0.80.10`，加入 Kimi K3、Kimi Coding HighSpeed、Grok 4.5 Responses 等最新模型元数据。
- 主会话、临时查询、自定义兼容端点和会话内模型切换统一迁移至官方 `ModelRuntime`。
- 新增进程内 CredentialStore，支持 API Key / OAuth 热更新与并发刷新串行化，不写入 Pi 默认 `auth.json`。
- GitHub Copilot 登录与刷新改用 provider-owned OAuth；Bedrock IAM 继续使用 AWS 环境与 SigV4。

## 插件与连接器改进

- 插件在 `@` 菜单中合并为一个顶层入口，由 Agent 选择内部技能；安装、启停和卸载后同步刷新技能与 MCP 工具。
- 插件和技能补齐品牌图标、兼容性报告、调用方式、认证状态和工具权限说明。
- MCP OAuth 保留资源、Scope、动态客户端和刷新凭据；仅允许批准宿主的服务会给出明确提示，不再借用其他应用身份。
- Gmail、Google Calendar、Google Drive、Slack、Outlook、Teams 与 SharePoint 等 Connector 可映射到 CA 原生认证数据源。

## 稳定性修复

- 修复浮动浏览器工具栏频闪、点击穿透、地址输入失效、固定状态失效与粗黑裁切边缘。
- 修复扩展商店包下载、Microsoft Edge 商店兼容和首次安装目录缺失。
- 修复 Windows 路径校验、TLS 测试证书、上传时序、WebUI 原生请求 mock、Electron mock 泄漏和网络 OAuth 测试依赖。
- macOS、Windows 与 Linux 打包脚本下载 Bun 运行时时支持持久缓存、断点续传、低速检测、多轮重试和官方 SHA-256 校验，临时网络中断后无需从零重新下载。
- 新增三平台交互式打包菜单，支持 Linux x64 AppImage；发行文件统一进入 `下载/Craft Pack`，中间目录与带时间戳日志分离，并修复跨平台包误带宿主机原生二进制的问题。
- 补齐多语言键值与跨平台测试覆盖。
