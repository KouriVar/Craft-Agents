# v0.11.6 - 稳定性、跨平台回归与视觉规范

这是一版以稳定性为核心的优化更新：不增加大型功能，也不改变 Craft Agents 现有视觉方向，重点解决内置浏览器状态、原生网页与应用浮层协调、跨平台窗口恢复、退出清理和问题诊断。

## 内置浏览器更稳

- 标签创建、恢复、切换和关闭增加明确的状态边界，避免重复新标签、关闭后的迟到事件回插，以及切换工作区时异步结果串线。
- 新标签页输入由 Craft Agents 界面直接承载，提交网址或搜索后才显示原生网页，改善 Windows 中文输入法、候选框、焦点与空白表面问题。
- 页面连续崩溃且自动恢复耗尽后会显示可操作的重新加载界面，并记录恢复次数用于诊断。
- 历史、收藏和下载改为事件驱动更新，移除周期轮询；切换列表时旧请求不会再覆盖当前结果。

## 原生网页与浮层协调

- 原生网页和 Dialog、菜单、Popover、Select、Drawer、通知、最新动态之间使用语义化暂停协议，多层浮层重叠时分别持有状态，关闭后按实际占用恢复。
- Tooltip 不再错误隐藏整张网页；菜单和通知不会被网页压住，关闭浮层后网页也不会无故保持消失。
- 浏览器菜单、下拉遮罩、弹窗、通知和全屏预览统一使用共享层级 token，减少任意 z-index 带来的层级回归。

## 跨平台窗口、退出与诊断

- 窗口位置会按当前显示器工作区修正，拔掉外接屏、改变虚拟机分辨率或系统缩放后仍能回到可见区域。
- 快速重复启动和 deeplink 会等待首个窗口准备完成，降低重复实例或启动期事件丢失风险。
- 退出清理覆盖浏览器、OAuth、模型刷新、消息网关、电源锁和服务锁；单个阶段失败不会阻止剩余资源释放。
- 应用设置新增“一键导出诊断包”，包含版本、平台/架构、Electron/Chromium、代理模式、浏览器崩溃、插件/MCP、启动里程碑和聚合资源占用。
- 诊断包不包含原始日志、网址、工作区路径、API Key、Cookie、Token、密码、PID、命令行或完整错误正文。

## 视觉规范基础

- Button、输入框、选择器、菜单、Tooltip、设置卡片、Dialog 与 Drawer 开始共用全局控件高度、圆角、间距和层级 token。
- 小窗口与系统缩放下，弹窗和浮层保留统一安全边距，超出内容在内部滚动。
- macOS 继续使用系统字体与苹方；Windows 继续使用内置思源黑体方案。
