# v0.11.8 - 更新缓存防回退修复

本版本修复 0.11.7 可能误用旧版更新缓存、在关闭应用后回退到 0.11.6 的问题。用户无需手动进入隐藏目录删除缓存。

## 自动恢复

- 0.11.8 首次启动会自动找到 Electron 打包配置指定的真实 updater 缓存目录，清理旧的 pending 安装包并记录一次性迁移状态。
- 已回退到 0.11.6 或仍在使用 0.11.7 的用户，只需手动安装一次 0.11.8。

## 防止再次降级

- 设置更新频道后显式关闭版本降级，避免 electron-updater 的频道默认行为重新允许旧版本。
- 普通关闭窗口或退出应用不再自动安装待处理缓存；只有用户明确选择安装/重启后才执行更新。
- 下载完成和安装前都会再次确认安装包版本严格高于当前版本，并且与本次更新清单一致。
- 删除仅凭缓存目录存在安装包就判定“更新已就绪”的旧回退逻辑，防止无版本信息的历史文件被误用。

Windows 和 Linux 仍保留用户确认后的自动安装与重新启动；未正式签名的 macOS 构建继续提供 GitHub Release 手动下载入口。
