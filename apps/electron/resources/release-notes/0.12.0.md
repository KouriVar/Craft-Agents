# v0.12.0 - 任务工作台、Git 环境与长期上下文

本版本进一步将 Craft Agents 收敛为以任务会话为核心的个人 AI 工作台，打通浏览器与会话，并补齐项目 Git 环境、长期记忆和跨入口附件恢复能力。

## 浏览器与会话工作台

- 浏览器标签右键菜单可直接打开或关闭右侧会话，审阅侧栏统一承载会话、浏览器、文件、终端、来源、快捷键、画布与插件组件；网页主视图移除常驻标题栏并恢复全高显示，不需要 AI 时仍可保持独立浏览。
- 浏览器工作区快照持久化任务归属，重启恢复网页后会重新绑定原任务，保留浏览器作为 Agent 工具的上下文连续性。
- 收敛探索导航菜单：网页筛选移除重复的新建入口，会话筛选将「看板」调整为搜索下方的单一入口，并修正「会话 / 网页」切换菜单的边界与左侧对齐。
- 「会话 / 网页」入口分别明确为「对话、执行与协作」和「浏览、分析与操作」；折叠主侧栏后仍保留模式切换器，不会中断当前工作流。

## 任务信息、会话状态与 Git 环境

- 会话右上角信息面板集中呈现上下文、任务上下文、会话文件、输出、来源和项目 Git 环境；输入框旁入口调整为「会话状态」，统一承载标题、会话文件、最近停点与模型用量。
- 新增完整 Git 工作流：查看变更与差异、暂存与取消暂存、提交、切换与新建分支、拉取、推送、同步、比较分支，以及查看和创建 GitHub PR。
- Git 环境会结合项目文件夹、代码文件、工具调用和开发意图智能出现；普通对话和非 Git 目录自动隐藏，代码任务中自动前置，并提供完整中文操作文案。
- 两个信息面板统一分区标题、卡片间距和自动隐藏的细滚动条，减少重复内容和视觉干扰。

## 长期上下文与跨入口恢复

- 项目页新增长期记忆编辑入口，可直接管理自动注入项目任务的 `MEMORY.md`，让记忆内容与调用范围可见、可控。
- 消息网关、自动化等非桌面入口的附件改由会话层统一落盘，重启或跨客户端恢复后仍可显示并继续使用。

## 工程与验证

- 版本统一升级到 `0.12.0`，同步所有 workspace 清单、锁文件和 README 版本标记。
- Electron 类型检查、Git 服务测试、会话分类、会话恢复与浏览器工作区相关验证通过，正式构建通过。
