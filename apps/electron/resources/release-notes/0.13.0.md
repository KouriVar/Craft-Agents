# v0.13.0 - 长期任务工作台、完整 Mermaid 与浏览器增强

本版本继续将 Craft Agents 收敛为以任务会话为核心的个人 AI 工作台：任务可以跨天持续、留下结构化检查点并按时提醒；探索首页开始主动整理今天需要处理的工作；同时补齐 Mermaid 官方图表能力和浏览器标签管理，让长期任务、知识表达与网页操作形成更完整的闭环。

## 新功能

- **长期任务状态** — 会话可设置长期目标、优先级、截止时间与提醒时间；会话状态面板提供保存检查点、删除检查点、标记提醒已处理和「继续任务」入口，让跨天、跨重启的事项不再只依赖聊天记录。
- **结构化任务检查点** — Agent 每轮完成、失败或中断后自动留下恢复点，从最终结果中分别提炼完成情况、下一步、阻塞项与相关文件；也支持手动保存检查点，随后可直接根据最近停点继续执行。
- **探索首页「今天」** — 新增统一任务队列，集中呈现到期提醒、逾期与今天截止事项、失败或等待中的执行、正在处理的工作、自动化结果、未读进展和可继续任务，并结合优先级与最近活动智能排序。
- **任务提醒与免打扰** — 到时提醒可通过系统通知触达，点击即可回到对应会话；探索设置新增提醒开关、主动建议开关及免打扰时段，已完成、已确认或已经通知过的任务不会重复打扰。
- **完整 Mermaid 图表引擎** — Markdown 图表改用 Mermaid 官方完整版，支持思维导图、时间线、甘特图、Git Graph、Sankey、Architecture、Requirement、Flowchart、Sequence、Class、State、ER、Pie、Journey、Quadrant、XY Chart 等官方语法，渲染、放大预览与 Agent 语法验证共用同一能力边界。
- **浏览器标签管理** — 网页标签右键菜单新增收藏、取消收藏、置顶、取消置顶、网站静音、取消静音、关闭其他标签页和关闭下方标签页；置顶状态随工作区保存，并稳定排列在标签列表顶部。

## 优化

- **长期上下文贯穿会话生命周期** — 任务目标、优先级、截止时间、提醒状态和检查点进入统一会话模型、磁盘持久化、RPC、远程迁移与自动化创建流程；消息网关或其他客户端恢复会话后仍可继续使用同一任务状态。
- **会话搜索更懂任务** — 搜索范围扩展到任务目标、项目与目录、标签、检查点摘要、下一步、阻塞项和相关文件，历史不再只是按标题与聊天预览查找。
- **看板展示真实进度** — 会话卡片补充目标、最近检查点、检查点结果、优先级与截止状态，无需进入会话即可判断任务当前处境；任务详情与卡片沿用 CA 的间距、色彩和信息层级。
- **工作简报使用长期上下文** — 探索页分析会结合任务目标、优先级、截止时间、最近检查点和下一步生成建议；「今天」与后续建议自动去重，避免同一会话在页面上重复出现。
- **自动化和远程入口统一落盘** — 自动化会话记录触发来源与时间，执行结果可直接进入「今天」继续处理；远程迁移同步完整任务上下文，桌面端、消息入口和自动化不再形成割裂的任务副本。
- **任务状态面板收敛** — 面板增加保存反馈、检查点数量、执行结果、阻塞项、相关文件和一键继续操作，同时移除与会话标题菜单重复的标题编辑区；会话文件区域按内容自动布局，不再使用僵硬的固定高度。
- **探索任务区重新设计** — 统一「今天」、工作概览和近期任务的标题、状态、辅助文案、间距与对齐，移除混杂的图标标签和机械编号，使任务优先级更清楚并贴合 CA 现有视觉语言。
- **探索模式实时恢复** — 应用持续保存最后使用的「会话 / 网页」模块，重启后回到离开前的工作模式；折叠侧栏时仍保留模式切换入口。
- **附件统计与描述统一** — 输入框动态区分附加文件和附加文件夹，文件夹显示真实数量并使用「附加文件夹」文案；会话文件区域和信息卡片同步适配内容数量。
- **浏览器菜单保持网页全屏** — 标签菜单与扩展子菜单限制在左侧导航区域，打开菜单时原生网页视图继续显示；批量关闭默认保护置顶标签，活动标签被关闭后会选择最近的可用标签。
- **多语言文案补齐** — 长期任务、今天、提醒设置和浏览器标签操作同步加入简体中文、英语、德语、西班牙语、匈牙利语、日语与波兰语资源。

## 修复

- **任务元数据不再被旧缓存覆盖** — 修复任务状态经外部更新、应用重启、跨设备迁移或延迟持久化后，目标、优先级、提醒和检查点可能被旧会话头写回的问题。
- **较早任务不会漏出「今天」** — 修复探索首页只检查最近一小段会话，导致历史任务的逾期事项与到时提醒无法进入任务队列的问题。
- **提醒严格去重** — 修复同一提醒在应用重启后重复投递的问题；已处理、已完成或已记录通知时间的任务不会再次触发系统通知。
- **文件夹附件正确计数** — 修复输入框只统计普通文件、文件夹始终没有动态数量的问题。
- **标签右键不再白屏** — 修复打开网页标签右键菜单或扩展子菜单时，Electron 原生页面被全局浮层策略隐藏、已加载页面暂时变成白屏的问题。
- **标签关闭回退更稳定** — 修复关闭活动标签或一次关闭多个标签后可能残留失效路由的问题，现在会优先切换到最近的存活标签，并阻止延迟状态事件复活已关闭标签。
