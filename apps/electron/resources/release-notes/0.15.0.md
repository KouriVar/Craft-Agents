# v0.15.0 — Cognition Layer 认知层

Craft Agents 迎来一次重要升级。

本版本新增 Cognition Layer（认知层），让 CA 从一个 AI 对话与执行工具，进一步成为能够理解个人工作状态的智能工作中枢。

## 新增能力

### 🧠 工作状态理解

新增完整认知链：

事件（Event）
→ 观察（Observation）
→ 闭环事项（Loop）
→ 工作复盘（Reflection）
→ 主动建议（Guidance）
→ Today


CA 现在可以：

- 记录工作过程中的重要变化
- 理解当前正在推进的事项
- 识别尚未完成的工作
- 提供下一步行动建议


---

### 📌 智能工作建议

Today 页面新增认知建议。

CA 会根据当前工作状态，展示：

- 值得继续推进的事项
- 尚未解决的问题
- 最近工作的延续方向


每条建议都保留来源依据，让你知道：

“为什么推荐这个？”


---

### 🔧 开发工作感知

新增 Git 工作状态感知能力。

CA 可以理解：

- Commit 提交
- Branch 分支变化
- Push 推送
- Sync 同步
- PR 变化
- 工作区状态


让代码开发过程也成为工作上下文的一部分。


---

### 🌐 工作上下文感知

新增浏览器工作上下文能力。

CA 可以理解：

- 正在研究的内容
- 关联的网页资料
- 当前工作背景


同时保持隐私边界：

不会记录密码、Cookie、Token 等敏感信息。


---

### 🔍 Cognition Debug

新增认知链调试能力。

可以查看：

事件
→ 观察
→ 闭环事项
→ 工作复盘
→ 建议


帮助理解 CA 如何形成每一次推荐。


---

## v0.15.0 的目标

从：

“能够调用 AI 的 Agent 工具”

升级为：

“能够理解长期工作状态的个人 AI 工作中枢”。


CA 不只是回答问题，也开始理解：

- 你正在做什么
- 你做到哪里
- 哪些事情还没有完成
- 下一步应该关注什么
