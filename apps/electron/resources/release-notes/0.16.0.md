# v0.16.0 — 隐私控制、Today 收敛与资源库

Craft Agents 本版本聚焦三件事：让上下文采集可控、让 Today 更干净可用，以及把会话整理成可编辑、可导出的文档。

## 隐私与上下文控制

你现在可以：

- 开关「上下文感知」与 Today 是否使用上下文
- 使用临时隐私模式
- 按来源（会话、浏览器、Git、文件、消息等）设置权限
- 查看上下文访问记录（不含正文）
- 清理 Cognition 派生数据

**说明：**

- 图片、Cookie、Token、密码不会被自动采集
- 清理 Cognition **不会**删除会话、资源库文档、MEMORY.md 或浏览器 Profile

## Today 收敛

首页 Today 区域更聚焦：

- **待处理**：可执行的本地强信号与受控的认知建议
- **最近使用**：会话与浏览器标签
- **稍后处理（Snooze）**
- **完成并归档**

并可在设置中分别隐藏：

- Today 区域
- 会话输入框

旧版 Explore Brief / 独立工作概览不再进入首页，避免重复推荐与自动消耗模型。

## 资源库

左侧新增「资源库」，支持：

- 空白文档
- **AI 整理成文档** / **原样保存为文档**
- 会话来源关联与章节来源
- 编辑、预览、自动保存
- 基础版本记录
- 归档与删除
- **Markdown / HTML / PDF** 导出

从会话生成文档前会请求授权；服务端使用一次性 Consent Token，客户端无法用布尔开关绕过。

文档生成信息（方式、模型、来源条数、质量状态）可在来源面板查看。

**隐私说明：**

- 资源库文档不属于 Cognition 派生数据
- 清除 Cognition 不会删除资源库文档

## 已知限制

- 超长会话生成文档时，可能要求你选择消息范围（不会静默截断）
- 从来源跳转会话时，暂时只打开会话，未必精确滚动到消息
- 极端复杂 Markdown 的 HTML/PDF 导出可能与应用内预览有细微样式差异
