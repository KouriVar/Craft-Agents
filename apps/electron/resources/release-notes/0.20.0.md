# CraftAgent v0.20.0

## 个人 AI 工作中枢，正式版

v0.20.0 是 CraftAgent 一次完整的产品重构。这个版本把过去分散在 Explore、Today、Task、Source、Plugin、Library 等入口里的能力重新整理成更清晰的工作系统：会话、浏览器、项目、自动化、知识库、动态和技能。

这次更新的目标不是单独增加某个页面，而是让 CraftAgent 更像一个可以长期使用的个人 AI 工作中枢：你可以从会话开始执行，把长期工作收进项目，把重要内容沉淀为知识，让自动化定时或按事件运行，并在动态中心处理结果、失败和需要确认的操作。

---

## 全新的工作区导航

左侧一级导航已经重新收口，默认围绕真实工作对象组织：

- **新建**：根据当前所在页面创建最合适的内容
- **会话**：日常对话、执行记录、子会话与看板
- **浏览器**：网页标签、历史、下载、书签和项目网页上下文
- **项目**：长期任务、项目会话、知识、文件、记忆和自动化
- **自动化**：定时、事件、Webhook、网页监控和可视化工作流
- **知识库**：可复用、可引用、可维护的知识内容
- **动态**：提醒、权限、失败、运行结果和连接状态
- **技能**：专家、技能、连接器与能力配置

设置与“最新动态”固定在左下角；“动态”只处理应用内待办和通知，“最新动态”只展示版本说明，两者不再混在一起。

旧 Explore、Today、Task、Source 与 Plugin 不再作为正式产品入口展示。历史深链会尽量跳转到新的对应页面，避免打开已经淘汰的界面。

> 书签数据和浏览器内收藏能力仍然保留，但左侧边栏的书签快捷区本版先隐藏，避免主导航过载。书签仍可以从浏览器相关界面与设置中管理。

## 新建动作会理解当前上下文

“新建”现在不只是一个固定按钮。CraftAgent 会根据你所在的位置提供对应动作：

- 在会话中创建新会话
- 在浏览器中打开新网页标签
- 在项目中创建项目或项目内容
- 在自动化中创建自动化、工作流或运行配置
- 在知识库中创建知识内容
- 在技能中添加专家、技能或连接器

这让常见操作少绕一层，也让不同功能之间的边界更自然。

## 会话与项目

项目现在是长期工作的核心容器，不再只是会话文件夹。

现在可以：

- 在项目内集中管理会话、知识、文件、记忆和自动化
- 为项目设置默认专家，新会话会自动继承项目上下文
- 在会话中按需覆盖专家配置
- 创建子会话并保留正确的上下文继承关系
- 固定重要会话，使用分支继续不同方向的工作
- 在看板中按状态组织会话，项目内看板会自动限制到当前项目范围
- 删除或归档项目时明确处理会话、知识、文件和自动化关系

在项目会话里使用 `@` 时，可以更明确地引用项目知识、项目文件或其他允许访问的资源，让 AI 使用的是你指定的材料，而不是模糊猜测。

项目归档后，相关自动化会暂停；恢复项目时需要你确认后再重新启用，避免旧自动化在不合适的上下文里突然运行。

---

## 浏览器成为正式工作区

浏览器现在是一级工作区，同时继续保留会话右侧浏览器能力。两处共享标签、登录态、历史和书签，不再拆成两套浏览器。

本版浏览器能力包括：

- 新建、切换、关闭和恢复网页标签
- 标签与 Workspace / 项目上下文关联
- 浏览器历史、下载和书签管理
- 查找、缩放、刷新、前进后退、外部浏览器打开
- 浏览器新标签页跟随应用外观
- 浏览器设置集中管理，不散落在其他页面中

同时修复了原生浏览器视图遮挡 React 浮层的问题。右键菜单、下拉菜单、Toast 和应用内通知出现时，浏览器视图会正确让出界面，不再盖住菜单或通知。

## 双 Command 截图到当前会话

macOS 上可以同时按下左右两个 Command 键，把当前屏幕截图放进已选中会话的输入框并自动聚焦。

这个动作不会自动发送消息，方便你先补充说明再交给 AI 处理。首次使用需要在 macOS“系统设置”里允许 CraftAgent 使用“辅助功能”和“屏幕录制”权限。

快捷键设置中也补充了相关配置入口，便于查看和管理。

---

## 知识库：把一次工作变成下次可用的能力

原先的 Library 已收口为**知识库**。已有内容会安全迁移，并保留来源、版本和项目隔离。

现在可以：

- 从会话中整理出可复用知识
- 原样保存重要会话内容
- 创建、编辑、归档和恢复知识文档
- 保留来源链、版本信息和项目归属
- 在会话、项目与输入框中通过 `@` 精确引用知识
- 使用全局搜索查找会话、项目、知识、文件和相关能力

升级时会先创建可恢复备份；迁移可重复执行，不会因为重复启动而重复搬运数据。遇到损坏、未知或来自未来版本的数据，CraftAgent 会停止覆盖并给出明确提示，而不是静默清空内容。

## 动态中心：该你处理的事集中在一起

动态中心是应用内通知和待处理事项的入口，不是普通聊天流。

它会聚合：

- 自动化完成、失败和有限重试结果
- 工作流运行状态与产出
- 权限请求和敏感操作确认
- 任务提醒和认知建议
- 连接器、消息通道与系统状态变化
- 可追溯的来源会话、项目和运行记录

你可以筛选动态、固定常用筛选条件，也可以静音不希望继续看到的规则。权限请求和失败事项会保留清晰状态，避免重要问题被误清掉。

需要授权的事项支持真实的**批准**与**拒绝**：批准后流程会从暂停处继续，拒绝后会留下明确结果，不再用笼统的“已处理”掩盖实际状态。

## 自动化与工作流

自动化现在统一承载定时任务、事件触发、Webhook、网页监控和工作流。

支持的触发方式包括：

- Cron 定时任务
- 应用内事件
- Webhook
- 网页变化监控
- 可视化工作流运行

创建自动化时，可以先用自然语言描述意图。CraftAgent 会生成草案，展示类型、触发条件、执行内容和所需权限；确认后才会保存和运行。

Webhook 会校验签名与重放风险；网页监控会校验 URL、规则和频率；无法安全执行的配置会明确报错，不显示假成功。

工作流编辑器支持：

- 顺序流程
- 条件分支
- 并行分支
- 会话与专家执行
- 连接器调用
- 知识库产出
- 项目文件产出
- 审批节点
- Run Session 追踪

每次运行都会创建可追溯的 Run Session。失败会记录原因并按规则有限重试；需要你确认的节点会暂停并进入动态中心。即使完全退出并重启应用，待审批状态仍会保留，批准后从暂停位置继续。

连接器节点会等待真实执行结果，不再以本地占位状态伪造“成功”。

## 技能与能力中心

“技能”现在是面向普通用户的统一能力入口，内部包含：

- **专家**：为不同类型工作设定角色、说明和可用能力
- **技能**：专家完成工作的操作方法
- **连接器**：连接外部服务、API、MCP 或本地工具

你不再需要先理解 Source、Plugin、Scope 等历史技术概念。项目可以设置默认专家，会话可以临时换用其他专家；技能和连接器会按照专家、项目和会话配置正确生效。

---

## 设置、外观与可靠性

设置页重新整理为更清晰的应用与 Workspace 配置，包括：

- 账号与集成
- AI、模型与记忆
- 权限与安全
- 外观与界面
- 输入与快捷键
- 浏览器、Messaging 与网络代理
- Workspace 配置

会话、浏览器、自动化、知识库、动态和能力中心现在共享更一致的三栏结构：左侧导航、中间列表或筛选器、右侧详情或主工作区。中栏标题、菜单、空状态、列表行、按钮密度和窗口背景也做了统一调整。

Windows 背景效果与 macOS 视觉表现做了额外收口，减少不同平台之间的界面割裂。

---

## 数据迁移与兼容

v0.20.0 为知识、自动化、工作流、动态、运行审计、网页监控、连接器能力与搜索索引增加了更明确的数据版本和迁移保护：

- 升级前自动创建可恢复备份
- 旧格式会安全迁移到新结构
- 迁移过程可幂等重复执行
- 损坏、未知或未来版本数据不会被静默覆盖
- 自动化、工作流和连接器失败会保留运行审计
- 旧深链会尽量重定向到新的正式页面

## 更新后建议试试

1. 从左侧“项目”创建一个长期工作项目，并设置默认专家。
2. 在项目内发起会话，使用 `@` 引用已有知识或文件。
3. 在“浏览器”中打开几个研究网页，并把网页关联到项目。
4. 在“知识库”保存一段会话成果，下一次再用 `@` 引用它。
5. 在“自动化”里创建一个定时任务或工作流，观察 Run Session 和动态通知。
6. 打开“动态”处理权限、失败和完成事项；打开左下角“最新动态”查看完整版本记录。

## 已知限制

- macOS 双 Command 截图首次使用需要系统授予“辅助功能”和“屏幕录制”权限。
- 第三方连接器的实际执行取决于对应服务授权状态、服务可用性和权限范围。
- 工作流首版不支持任意循环，避免不可终止或成本不可预测的自动化。
- 跨平台安装包仍建议在目标平台完成一次手工启动和基础工作流验证。
