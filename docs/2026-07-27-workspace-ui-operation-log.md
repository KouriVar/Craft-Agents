# 工作区界面修复操作日志

日期：2026-07-27

## 会话与全局新建

- 左上角主创建按钮改为直接显示当前导航对应的动作：新建会话、新建网页、新建项目、新建自动化、新建知识文档或新建专家。
- 未命中具体产品导航时继续回退为“新建会话”。
- AI 推荐按钮改用与执行/当前会话一致的最小阴影、边界感和悬浮背景。
- 会话菜单的 `Pin session` 默认文案改为“置顶会话”。

## 浏览器

- 中栏标题从错误的“所有会话”改为“所有标签”，收藏、历史、下载也显示各自标题。
- 新标签页创建时读取应用已经解析好的浅色/深色外观；“自动”模式使用应用解析后的系统结果。
- 菜单、弹层和应用通知出现时暂停原生浏览器视图，避免原生层覆盖界面浮层。

## 自动化

- 隐藏未完成设计的工作流编辑器入口。
- 恢复“自动化列表 → 自动化详情”的三栏路径；未选择时显示明确的选择提示。

## 知识库

- 删除中栏内重复的标题、副标题和“新建 Markdown 文档”按钮。
- 导入、思维导图、搜索及全部/最近/已归档筛选统一收进中栏标题右侧菜单。
- 文档详情工具条改为会话详情同类图标按钮；保存版本、复制、导出、归档和删除收进更多菜单。
- 来源段落、关联会话、生成信息、项目与版本记录收进右上角信息面板。

## 动态

- 中栏标题修正为“动态”，不再显示“所有会话”。
- 新增动态列表中栏与选中项详情页，恢复三栏结构。
- 全部、待处理、自动化、系统筛选以及“全部已读”收进标题右侧菜单。

## 技能 / 能力中心

- 恢复三栏结构。
- 标题右侧菜单提供专家、技能、连接器切换，并在中栏展示对应列表、右栏展示详情。
- 左上角主创建动作会随专家、技能、连接器上下文切换为新建专家、新建技能或新建连接器。
- 清理了遗留的“技能页无详情时隐藏中栏”规则，保证三个能力分类始终保持三栏布局。

## 设置与截图

- 裸设置路由默认选中“通用”。
- “快捷键”恢复为设置左侧的常驻入口，不再只能从会话页的上下文按钮进入。
- “设置 → 快捷键 → 屏幕截图”新增“双 Command 截图”开关和运行状态说明。
- 截图仍只添加到当前会话输入框草稿，不会自动发送。

## 验证

- Electron TypeScript 类型检查通过。
- Shared TypeScript 类型检查通过。
- 路由、动态路由、创建动作、浏览器意图、浮层检测和通道映射定向测试通过。
- Electron renderer 生产构建通过。
- 使用独立配置目录启动 Electron 开发版，逐页核对会话、浏览器、自动化、知识库、动态、技能和设置。
- 已验证浏览器筛选菜单能显示在原生网页层之上，新标签页 URL 携带应用解析后的 `appearance=dark`。
