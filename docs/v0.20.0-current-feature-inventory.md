# CraftAgent v0.20.0 当前功能全量清单

> 用途：作为 v0.20.0 功能增、删、改、并的底稿。  
> 基线：当前 `my-changes` 分支（已合入上游 v0.11.2）。  
> 口径：按“用户或 Agent 能完成的动作”计数，不把约 300 个 IPC/RPC 通道逐个当成功能。

本版共列出 **498 个带编号的功能/缺口检查项**，另有 **22 个废弃、隐藏或半成品候选项**。同一底层能力在不同产品场景中的动作会分别计入，例如“浏览历史单条删除”和“清空全部历史”是两个用户决定；22 个候选项与前面的功能项可能交叉，不应直接相加理解为 520 个独立功能。

核对来源包括当前路由、设置页、RPC 定义与处理器、Session Command、Agent Tool Registry，以及 DeepSeek、hy3 两套审计报告。旧报告与当前代码冲突时以当前代码为准。

## 0. 怎么读这份清单

### 状态图例

| 标记 | 含义 |
|---|---|
| ✅ | 已实现，存在正常产品入口 |
| 🟡 | 已实现但入口较深、体验不完整或仅覆盖部分场景 |
| 🟣 | 隐藏能力：后端/RPC/数据结构存在，正常 UI 很难或无法触达 |
| 🧪 | 实验性、调试性或完成度不足 |
| ❌ | 未实现 |
| 🪦 | 废弃、孤立或不应继续扩展 |

### v0.20.0 处置栏建议填写

- `留`：原样保留
- `改`：保留能力，重做交互或实现
- `并`：并入另一个功能/页面/概念
- `删`：删除代码和产品入口
- `藏`：保留底层能力，不进入主导航
- `补`：补齐缺失的 CRUD 或闭环

## 16. 功能交叉与合并候选

| 交叉组 | 现在的重叠 | 推荐的新边界 |
|---|---|---|
| Expert / Skill / Source / Plugin | Expert 尚无；Skill 是方法；Source 是连接；Plugin 又能同时提供 Skill/MCP/Connector | Expert = 可选择的角色配方；Skill = 方法；Connector = 外部能力；Plugin = 安装包，不做一级心智 |
| Source / MCP / Connector | MCP 是协议，Source 是当前配置对象，Connector 更像用户能理解的产品词 | UI 统一叫 Connector；内部保留 API/MCP/Local Driver |
| Plugin Skill / Workspace Skill / Project Skill | 同一 Skill 有 5 个 Scope，用户难判断来源和覆盖关系 | 统一技能库，详情显示“来源、作用域、继承与覆盖” |
| Library / Project Assets / Memory | 都在保存“给 Agent 使用的内容”，但入口和生命周期不同 | Library = 可复用知识；Asset = 项目文件；Memory = 自动/人工维护的偏好和事实 |
| Session Status / Kanban Column / Task | 三者都在表达工作进度 | 选一个统一 Work Item 模型，Session 是执行记录 |
| Task / Automation / Checkpoint | 都能表达执行、状态和恢复 | Task = 工作对象；Automation = 触发规则；Run = 每次执行；Checkpoint = Run 内部恢复点 |
| Today / Reminder / Notification / Cognition Guidance | 都会产生“现在该处理的东西” | 汇入统一 Inbox/Activity Center |
| Privacy / Permissions / Accounts | 分成三个设置区，实际共同管理身份、凭据、访问和授权 | 合并为“安全与访问”设置 |
| Browser Extension / Craft Plugin | 都叫插件，但完全不是同一系统 | UI 明确叫“浏览器扩展”和“能力包” |
| Settings / Sources / Plugins / Skills | 同一对象同时在主页面和设置里出现 | 安装与浏览放“能力中心”，全局策略留在设置 |
