# CraftAgent v0.20.0 Electron 人工烟测清单

## 1. 启动前

- [ ] 备份 `~/.craft-agent`。
- [ ] 从当前 worktree 执行 `bun run electron:build`。
- [ ] 使用隔离 profile 或已备份的真实升级 profile 启动。
- [ ] 记录 OS、架构、应用版本、安装包哈希和测试时间。

## 2. 导航和布局

在普通窗口与明显更高的窗口各执行一次：

- [ ] 一级顺序严格为：新建、会话、浏览器、项目、自动化、知识库、动态、技能。
- [ ] 无“新建网页、Sessions、Explore、Today、Task、Source、Plugin、定时任务、事件触发、智能体”等旧一级入口。
- [ ] 设置、最新动态位于真正左下角固定区；增高窗口后仍贴底，底部下方无大片空白。
- [ ] 无未来扩展内容时不显示空占位。
- [ ] 分别打开浅色、深色；关闭并重启，主题仍保留。

## 3. 上下文“新建”

- [ ] 会话页：创建新会话，输入框自动聚焦。
- [ ] 浏览器页：创建空白标签页。
- [ ] 项目页：打开新建项目入口。
- [ ] 自动化页：打开自然语言草案对话框。
- [ ] 知识库页：创建文档。
- [ ] 技能页：打开新建专家对话框。
- [ ] 任一动作取消后不得留下“成功”记录。

## 4. Dynamic 与最新动态

- [ ] “动态”显示应用内通知/失败/权限/提醒/连接状态。
- [ ] 未读、今天、较早、固定筛选和静音规则可操作并在重启后保留。
- [ ] 会话来源跳到正确会话；Run Session 来源跳到正确运行。
- [ ] 项目来源跳到准确项目，而不是列表首页或其他项目。
- [ ] 权限事项提供真实批准/拒绝；重复点击或过期请求显示明确结果，不显示通用“已处理”。
- [ ] “最新动态”只显示 Release Notes，且与 Dynamic 是两个页面。

## 5. 核心 CRUD 和持久化

- [ ] 浏览器：新增、切换、关闭标签；历史/书签按产品支持范围验证；离开页面后原生网页不覆盖其他页面。
- [ ] 项目：新建、编辑、归档；工作目录外数据不被删除。
- [ ] 知识库：新建、编辑、删除/回收站；重启后内容和版本仍在。
- [ ] 搜索：按会话、知识、项目文件等来源搜索；项目 A 不出现项目 B 的私有结果。
- [ ] 专家：新建、复制、编辑、删除；被删除 ID 有清晰降级。
- [ ] 技能/连接器：真实 CRUD；无效凭据或远端失败显示失败而不是本地假成功。
- [ ] 项目默认专家、会话覆盖、子会话继承符合配置。

## 6. 自动化和工作流

- [ ] 自然语言只生成草案；用户确认前不得保存或运行。
- [ ] UI 明确显示由模型推断还是规则回退。
- [ ] Cron 保存后能在到期时真实创建 Run Session。
- [ ] Webhook：有效 HMAC 触发一次；无效签名、重放和下游失败可见。
- [ ] 网页监控：实际轮询；首次建基线，内容变化触发，失败退避并进入 Dynamic。
- [ ] 文件、项目和 Messaging 事件各触发一次真实自动化。
- [ ] 顺序、条件、并行、会话/专家、连接器、知识库产出、项目文件产出逐节点运行。
- [ ] 失败按配置执行有限重试；运行详情和 Dynamic 可定位最终失败。
- [ ] 项目归档暂停关联自动化；恢复项目时必须选择并确认重新启用项。
- [x] 审批节点可暂停、重启恢复、批准后继续；拒绝终止及重复决策由 RPC 测试覆盖。Electron 证据见 Phase 9 截图 15–17。
