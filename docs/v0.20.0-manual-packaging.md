# CraftAgent v0.20.0 手工打包与安装验证

本说明只使用仓库现有脚本，不新增或重构跨平台 CI。建议在目标操作系统原生构建，尤其是 Windows 安装包和平台原生依赖。

## 1. 通用准备

```bash
bun install --frozen-lockfile
bun run validate:ci
bun run electron:build
git diff --check
```

打包前确认：

- package manifests、`bun.lock`、README 均为 0.20.0。
- `apps/electron/resources/release-notes/0.20.0.md` 已进入构建资源。
- 工作区没有意外生成的凭据、用户数据或备份。
- 本机签名、公证、证书和发布凭据按团队发布策略配置；不要把凭据写入仓库。

## 2. macOS

Apple Silicon：

```bash
bun run electron:dist:mac
```

Intel：

```bash
cd apps/electron
bun run dist:mac:x64
```

验证：

- 在干净用户或测试机安装 DMG。
- 检查签名、公证和 Gatekeeper。
- 完成浅/深色、导航、持久化和双 Command 截图烟测。

## 3. Windows

在 Windows PowerShell 中：

```powershell
bun install --frozen-lockfile
bun run validate:ci
bun run electron:build
cd apps/electron
bun run dist:win
```

仓库也提供 `bun run electron:dist:win` 的跨平台 bash 包装，但正式验收优先使用 Windows 原生 `dist:win`。

验证：

- 在干净 Windows 用户上安装生成的安装程序。
- 检查 SmartScreen/签名、开始菜单、快捷方式、升级和卸载。
- 验证浏览器原生视图、文件事件、Webhook、重启持久化。

## 4. Linux

x64：

```bash
bun run electron:dist:linux
```

如需 arm64，使用现有脚本：

```bash
cd apps/electron
bash scripts/build-linux.sh arm64
```

验证：

- 在目标发行版安装生成的包。
- 检查桌面入口、沙箱/权限、系统托盘及升级/卸载。
- 验证文件监听、浏览器原生视图、自动化和重启持久化。

## 5. 每个平台的最小安装后路径

1. 启动并确认版本 0.20.0。
2. 核对一级导航顺序和左下角固定区。
3. 切换浅/深色并重启。
4. 新建会话、浏览器标签、项目、知识文档和自动化草案。
5. 触发一个成功自动化和一个明确失败自动化；从 Dynamic/运行详情定位。
6. 验证项目归档暂停关联自动化，恢复时要求确认。
7. 验证旧 Explore/Today/Task/Source/Plugin URL 不复活旧正式页面。
8. 完成 `docs/v0.20.0-electron-manual-smoke-checklist.md`。
9. 保存安装包 SHA-256、签名状态、系统版本和截图。

当前审计结论为有条件可发布；只有完成 macOS 双 Command 系统权限手势、真实第三方连接器和三平台安装验收后，才可制作正式发布包。
