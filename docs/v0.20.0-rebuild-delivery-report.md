## 3. UI Fixes

### Settings Navigator Consolidation
- **Before**: 14 pages in flat list (app, ai, accounts, appearance, privacy, cognition, input, workspace, permissions, labels, messaging, server, shortcuts, preferences)
- **After**: 9 formal pages in 5 logical groups:
  - General: app
  - AI & Memory: ai, preferences
  - Appearance & Input: appearance, input, shortcuts
  - Workspace: workspace
  - Security & Access: accounts, permissions

### App Menu Consolidation
- Desktop and mobile app menus now show only 9 formal settings pages
- Hidden pages (privacy, cognition, labels, messaging, server) removed from menu

### Route Parser Fixes
- Settings route `settings` now correctly preserves bare route (no longer adds default `app` subpage)
- Sources routes no longer incorrectly redirect to skills navigator
- Hidden settings pages safely redirect:
  - privacy → permissions
  - cognition → app (general)
  - labels → appearance
  - messaging → accounts
  - server → workspace
